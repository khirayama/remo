# Remo iOS

SwiftUI製のタイムラインアプリです。認証済みのトークンはKeychainへ保存し、Timeline recordのメタデータは端末内のSQLite（`LogDatabase`）を正本として保存します。メモリに持つのは表示中の1日と写真記録だけで、他の日・エクスポート・未バックアップの記録はインデックスから読みます。ログイン中は写真ごとの縮小JPEGをR2へバックアップし、別端末ではクラウドの画像を表示します。元写真と動画本体は端末内に残します。

初回起動時に説明画面を表示し、「記録を始める」を選ぶと位置情報・モーション・写真の許可を確認して、Core Locationが自動で位置を記録します。移動中は通常10秒、十分な静止判定後は5分間隔へ自動で切り替え、静止中は測位精度を下げてGPSを休ませます。「常に許可」を選ぶとバックグラウンドでも動作し、アプリが終了された後や端末の再起動後も、大幅位置変更の通知でシステムがアプリを再起動して記録を再開します。設定から停止できます。外観はシステムのライト／ダーク設定に従います。画面構成とデザイントークンはAndroidを正本としてそろえています。地図の上に設定・記録状態・現在地・全体表示のボタンを置き、日付・サマリー・タイムライン・滞在した場所は下部シートにまとめています。滞在の場所名と時間は地図の円をタップすると表示します。写真ライブラリは撮影日時と位置だけを端末内で読み込みます。

写真一覧から写真を開き「位置を補正」を選ぶと、写真自身を除外した、撮影時刻の前後15分以内にある精度100m以下の加工済み位置ログから候補を表示します。未確定のEXIF写真は地図・Timeline上でもその加工済み位置へ表示上自動配置します。候補の適用、地図タップ、緯度経度の手入力、位置情報の削除、元のEXIFへの復元に対応し、元のEXIFへ戻した写真は自動配置しません。写真を同じ日・同じ位置でまとめているため、補正単位は写真グループです。元のEXIF位置は端末と同期データに保持します。

選択日内の滞在ポイントは、代表座標が100m以内の別滞在を同じ場所としてまとめ、訪問回数ごとに表示します。端末のCLGeocoderが返すプレイス名・住所を滞在ポイントと地図上に表示します。住所は端末内の表示用で記録・同期データには保存しません。訪問履歴から場所に名前を付けると、その名前を優先して表示し、ログイン中は同期します。

設定画面から開始日・終了日を指定して、位置と写真メタデータをJSONへ共有できます。JSONのインポートにも対応し、読み込んだ記録は端末へ統合してバックアップします。写真画像本体は共有データへコピーしません。設定画面ではバックアップ状況も確認できます。

バックアップは、まだバックアップしていない記録と削除だけを400件ずつ送り、応答ごとに送信済みにします。クラウドの読み取りは最新カーソルに変更があるときだけ行い、受け取ったページごとに保存します。他の端末の編集は新しければ取り込み、他の端末で1件ずつ削除された記録は端末からも削除します。画面表示中の同期とバックグラウンド更新は同じ`BackupCoordinator`を通り、同時には動きません。

`Remo/PrivacyInfo.xcprivacy` に、収集するデータ（正確な位置情報・写真・メールアドレス。いずれもアプリの機能のためで、トラッキングには使いません）と、理由の申告が必要なAPI（UserDefaults・ファイルのタイムスタンプ・システム起動時刻）を記載しています。

```bash
xcodegen generate
xcodebuild -project Remo.xcodeproj -scheme Remo -destination 'generic/platform=iOS Simulator' CODE_SIGN_IDENTITY="-" build
```

シミュレータからは`http://localhost:8787`のAPIへ接続します。別のAPIを使う場合は`project.yml`の`REMO_API_BASE_URL`を変更してください。
