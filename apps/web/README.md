# Remo Web

React + Vite + Leafletで、位置情報（移動中10秒／静止時5分）と写真を日付単位の地図Timelineとして表示します。選択日内の近い滞在区間は表示上の滞在ポイントへまとめ、訪問回数ごとにセクション化します。ブラウザ版では住所を外部サービスへ送らず、滞在ポイントは座標で表示します。

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

`VITE_API_BASE_URL`をRemo APIのURLへ合わせてください。

初回表示時にブラウザの位置情報許可を確認し、許可後は自動で位置記録を開始します（移動中は通常10秒、十分な静止判定後は5分間隔。設定から停止できます）。ブラウザを閉じた後の取得は行いません。画面構成はAndroid版に合わせ、全面の地図に設定ボタンと記録状態を重ね、日付・その日の概要・時系列の記録一覧をシート（狭い画面では下部シート、広い画面では左パネル）にまとめています。書き出し・読み込み・写真の追加・削除は設定画面から行います。写真は複数選択して追加でき、未確定のEXIF写真は撮影時刻に近い加工済み位置ログへ表示上自動配置します。候補の適用、地図クリック、緯度経度入力による補正もでき、明示的に元のEXIFへ戻した写真は自動配置しません。ログイン中は撮影日時・位置・枚数と補正メタデータに加え、縮小JPEGをバックアップします。元画像と動画本体は送りません。

バックアップは記録の書き込みとクラウドの読み取り確認を分離し、未送信の変更は先にbatch送信します。最新カーソルに変更がない場合は本体データを取得せず、位置記録の粒度は変更しません。

ローカルでサンプルを確認する場合は、リポジトリルートの `fixtures/timeline/*.sample.json` を「設定 → JSONをインポート」から読み込んでください。エクスポートは開始日・終了日を指定でき、期間内の位置と写真メタデータを JSON に含めます（画像本体は含みません）。
