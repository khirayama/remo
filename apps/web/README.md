# Remo Web

React + Vite + Leafletで、位置情報（移動中10秒／静止時5分）と写真を日付単位の地図Timelineとして表示します。選択日内の近い滞在区間は表示上の滞在ポイントへまとめ、訪問回数ごとにセクション化します。ブラウザ版では住所を外部サービスへ送らず、滞在ポイントは座標で表示します。訪問履歴から場所に名前を付けると、座標の代わりにその名前を表示します。

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

`VITE_API_BASE_URL`をRemo APIのURLへ合わせてください（ローカルは `http://localhost:8787`）。本番ビルドは空にし、Web自身のWorker（`worker/index.ts`）が `/api/*` をService Bindingで `remo-api` へ中継します。同一オリジンになるため、SafariやFirefoxでもセッションCookieがブロックされません。

地図タイルは既定でOpenStreetMapのタイルサーバーを使います。OSMのタイルサーバーは軽い利用だけが許可されているため、公開運用では `VITE_MAP_TILE_URL`（Leafletのタイル URL テンプレート）と `VITE_MAP_TILE_ATTRIBUTION` にタイル提供事業者の値を設定してください（`just web-deploy tiles=... attribution=...`）。未設定の本番ビルドは警告を出します。

記録はIndexedDB（`remo-timeline`）に1記録1行で保存します。メモリに持つのは表示中の1日だけで、他の日・エクスポート・未バックアップの記録は開始時刻と同期状態のインデックスから読みます。旧版のデータ（IndexedDB v1、`localStorage`）は初回起動時に移行します。設定画面の「データ」に件数と保存容量を表示します。

ログインすると、このブラウザの記録はそのアカウントへバックアップされます。別のアカウントの記録が残っているブラウザでログインした場合は、記録をそのアカウントにも保存するか、削除して切り替えるかを確認します。共有のパソコンを考慮し、ログアウト時に「記録を削除してログアウト」を選べます。

本番ビルドは `dist/client/_headers` にCSPなどのセキュリティヘッダーを生成します。許可するのは自身のスクリプト、Webフォント、設定した地図タイルとAPIだけです。外観はシステムのライト／ダーク設定に従います。

初回表示時に説明のダイアログを表示し、「記録を始める」を選ぶとブラウザの位置情報許可を確認して自動で位置記録を開始します（移動中は通常10秒、十分な静止判定後は5分間隔。設定から停止できます）。ブラウザを閉じた後の取得は行いません。画面構成はAndroid版に合わせ、全面の地図に設定ボタンと記録状態を重ね、日付・その日の概要・時系列の記録一覧をシート（狭い画面では下部シート、広い画面では左パネル）にまとめています。書き出し・読み込み・写真の追加・削除は設定画面から行います。写真は複数選択して追加でき、未確定のEXIF写真は撮影時刻に近い加工済み位置ログへ表示上自動配置します。候補の適用、地図クリック、緯度経度入力による補正もでき、明示的に元のEXIFへ戻した写真は自動配置しません。ログイン中は撮影日時・位置・枚数と補正メタデータに加え、縮小JPEGをバックアップします。元画像と動画本体は送りません。

バックアップは、まだバックアップしていない記録と削除だけを400件ずつ送り、応答ごとに送信済みにします。クラウドの読み取りは最新カーソルに変更があるときだけ行い、受け取ったページごとに保存します。他の端末の編集は新しければ取り込み、他の端末で1件ずつ削除された記録はこのブラウザからも削除します。セッションが切れたときは「再ログインが必要です」と表示します。

ローカルでサンプルを確認する場合は、リポジトリルートの `fixtures/timeline/*.sample.json` を「設定 → JSONをインポート」から読み込んでください。エクスポートは開始日・終了日を指定でき、期間内の位置と写真メタデータを JSON に含めます（画像本体は含みません）。
