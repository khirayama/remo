# Remo

Remoは、設定した間隔の位置情報と写真・動画を、日付ごとの地図タイムラインにまとめるアプリです。

## 構成

| パス | 内容 |
| --- | --- |
| `apps/api` | Cloudflare Workers + D1 + R2 + Better Auth。記録と縮小写真の同期 |
| `apps/web` | React + Vite + Leaflet。日付切替付きの地図Timeline |
| `apps/android` | Jetpack Compose。Foreground Serviceによる位置記録と写真ライブラリ |
| `apps/ios` | SwiftUI。Core Locationによる位置記録とPhotoKit |

## 現在の機能

- 移動中は通常10秒間隔、十分な静止判定後は5分間隔で位置情報を取得（Webはタブ表示中のみ）し、時刻・緯度・経度を保存
- 写真・動画ライブラリを読み込み、撮影日時・EXIF位置をTimelineへ追加
- Android・iOSでは、許可するとヘルスコネクト／ヘルスケアの睡眠（就寝・起床の時刻と時間）を起床した日のTimelineに表示。端末にもクラウドにも保存せず、表示とJSONエクスポートのたびに読み取る（Webにはブラウザから睡眠を読める手段がないため対応しない）
- Android・iOSの設定画面に位置情報の許可の状態を表示。「常に許可」でない場合と、おおよその位置だけが許可されている場合は注意を表示し、その場から許可を広げられる
- 写真時刻に近い加工済み位置ログからの補正候補表示と、未確定のEXIF写真の地図・Timeline上での自動配置。地図クリック・緯度経度入力による手動補正（元のEXIF位置を保持）にも対応
- 選択した日付の全位置サンプルを地図上の線で表示し、現在地も表示
- 選択した日付の記録を時刻順に表示
- 選択日内の近い滞在区間を滞在ポイントとしてまとめ、訪問回数ごとのセクションで表示。Android/iOSでは端末の逆ジオコーディングによるプレイス名・住所も表示
- 地図を「すべて」に切り替えると、全期間の滞在場所を訪問回数順に地図と一覧で表示（過去日の滞在判定は端末内にキャッシュ）
- 滞在地点ごとに全期間の訪問履歴（訪問回数・日数・合計時間・日ごとの滞在時刻）を表示し、日付からその日のタイムラインへ移動
- 場所に名前（「自宅」「職場」など）を付けると、座標や住所の代わりに表示。ログイン中は端末間で同期
- ログインしていなくても端末を正本として保存し、閲覧・自動記録・JSONエクスポート／インポートを利用可能。ログイン後は記録と縮小写真をクラウドへ自動バックアップし、Webや他デバイスから閲覧可能。他の端末での写真位置の補正や個別の削除も反映
- システムの外観に合わせたダーク表示
- 期間を指定したJSONエクスポート（位置・写真メタデータ）と全データ削除
- パスワード確認付きのアカウント削除（クラウドのバックアップも削除し、端末の記録は残す）

位置情報の自動取得は、初回起動時に何を記録するかを説明したうえで権限を確認し、許可後は自動で開始します（設定から停止できます）。ログインは不要です。移動中10秒、十分な静止判定後5分へ自動で切り替えます（Webはタブ表示中のみ）。取得した位置と元写真は端末へ保存します。設定からログインすると、時刻・位置・枚数に加え、再圧縮したサムネイルを自動バックアップします。元写真や動画本体はアップロードしません。

## ローカル起動

Node.js 24.22.1（`.nvmrc`）と npm 11 または 12、`just` を使用します。nvm を使う場合は最初に `nvm install && nvm use` を実行してください。

```bash
just setup
just api       # http://localhost:8787
just web       # http://localhost:5173
```

`just setup` はロックファイルどおりに依存関係をインストールし、API の `.dev.vars` と Web の `.env` をサンプルから作成します。既存の設定ファイルは上書きしません。Web の開発サーバーは `localhost:5173` で起動し、ポート使用中は停止するため、別ポートへ変わって認証の許可オリジンと食い違うのを防ぎます。

`just check` で API・Web の型検査、テスト、ビルド（API はデプロイなし、Web は開発・本番の両方）、`just audit` で開発用も含む npm 依存関係の脆弱性監査を実行できます。Android は `just android-check`、iOS は `just ios-check` を使用します。GitHub Actions では PR・main への push・週次で API・Web・Android を検証し、Dependabot が npm・Gradle・Actions の更新を提案します。

ローカル確認用のタイムラインデータは [`fixtures/timeline/`](fixtures/timeline/) にあります。Web の「設定 → JSONをインポート」から `*.sample.json` をインポートして使用できます。エクスポートは開始日・終了日を指定でき、写真は画像本体ではなく撮影日時・位置・枚数のメタデータとして含まれます。

エクスポートしたJSONは `python3 tools/analyze-export.py <export.json>` で、日ごとの測位数・精度・間隔・記録の欠落を確認できます。Androidのエクスポートには記録の診断ログが含まれ、モード別の時間と電池消費、滞在を終えた合図、測位1件ごとの種類と飛びなども集計します。`just timeline-report <export.json>` は、同じJSONからTimelineが作る滞在と移動を日ごとに一覧し、日付・時間帯・出力先を付けると、記録した測位と地図に描く線をSVGに重ねて出力します。

AndroidはAndroid Studioで`apps/android`を開き、iOSは`apps/ios/Remo.xcodeproj`を開いて起動します。
